## 免费/顺路打卡点

U 型公路、小柴旦湖、硫磺湖、南八仙魔鬼城、阳关（可选）——均为路边停车即可拍摄，无需门票。

## 摄影相关

- **日出点**：青海湖黑马河（9.27）、鸣沙山（9.30）、七彩丹霞（10.2）
- **日落点**：茶卡盐湖（9.28）、鸣沙山（9.29 傍晚）、七彩丹霞（10.2 傍晚）
- **星空**：大柴旦 9.28 晚最佳（亏凸月 54%，前半夜暗黑窗口 20:30–23:00）
- **无人机**：翡翠湖、黑独山、察尔汗盐湖允许飞，需提前确认禁飞区

## 2026 年时效性变化（重要）

1. **黑独山**：2025-05-21 起正式开放为景区，免门票但强制景交车 ¥60，禁止自驾进入
2. **大柴旦翡翠湖**：2026 年起收费（门票 ¥50 + 观光车 ¥40），原 2023 版标注"免费"已过时
3. **鸣沙山**：已全面线上售票，现场无人工窗口，可提前 15 天预约
