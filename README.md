# 青甘环线 · 西行计划（2026.9.26–10.6）

> **5 人自驾摄影团 · 1 辆 SUV · 正向环线（顺时针）· 11 天 10 晚**
> 当前执行版行程：**v5.1**（2026-08-30）。最新精简汇总见 [`当前版行程与住宿计划.md`](当前版行程与住宿计划.md)。

## 项目简介

2026 年国庆前青甘大环线自驾旅行：西宁 → 青海湖 → 茶卡 → 大柴旦 → 冷湖（黑独山）→ 敦煌 → 嘉峪关 → 张掖丹霞 → 祁连 → 西宁。以摄影为导向（晨光窗/平光槽/斜光窗三原则排程），大柴旦、敦煌压在节前（9.27–9.30），国庆正日只住张掖、祁连两晚，住宿成本最优。

**最新变更（v5.1，8.30）**：莫高窟常规 A 类票已订 **9.30 15:00 场**（原 9.29 14:30 作废），敦煌两日重排——9.29 转场+鸣沙山日落首刷，9.30 为「鸣沙山日出二刷 → 莫高窟 15:00 → 《又见敦煌》20:00」三锚点日。

## 行程变更跨维度同步流程（必读）

> **任何行程变化（日期、场次、住宿地、交通方式调整）都必须触发以下流程**，保证全仓一致性。此流程自 2026-08-30（v5.1 莫高窟改期）起生效。
> 🤖 本流程已沉淀为项目级 skill：`.catpaw/skills/trip-sync/SKILL.md`——在 CatPaw 中打开本仓库时，行程变化会自动触发该 skill 执行；方法论背景见 `Reference/方法论-行程变更跨维度同步.md`（本地）。

1. **改主文档**：更新 `最新行程表-v5.md`（升小版本号并在文首标注变更），重排受影响日段并写明连锁调整逻辑与风险。
2. **改汇总**：同步 `当前版行程与住宿计划.md` 的行程主表、抢票日历、决策记录。
3. **扫维度**：全仓 grep 变更关键词（如日期、景点名），逐个更新：
   - `娱乐/`：游玩项目全攻略（对应时间/总览表/抢票时间轴/逐时段明细）、预约清单；
   - `住/`：README 当前计划表与预订节奏，必要时更新详细方案；
   - `行/`：README 路线骨架表、交通方案-简洁版；
   - `docs/index.html`（及 `web/index.html` 副本）：网页端对应日程卡片。
4. **核对一致性**：改完后 grep 旧日期/旧场次确认无残留（注意排除 `archive/` 与 `Reference/`）。
5. **提交推送**：commit message 注明变更内容与触发的同步范围。
