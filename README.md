# 青甘环线 · 西行计划（2026.9.26–10.5）

> 8 人自驾摄影团 · 10 天 9 晚 · 两个路线方案对比

## 项目简介

本仓库为 2026 年国庆前青甘大环线自驾旅行的总体行程规划。同一行程骨架（西宁出发环线，覆盖青海湖、大柴旦、敦煌、嘉峪关、张掖、祁连）提供两种走法：

- **正向环线（顺时针）**：西宁 → 青海湖 → 茶卡 → 大柴旦 → 敦煌 → 嘉峪关 → 张掖 → 祁连 → 西宁
- **反向环线（逆时针）**：西宁 → 祁连 → 张掖 → 嘉峪关 → 敦煌 → 大柴旦 → 青海湖 → 西宁

两者里程和驾驶强度基本相同，核心差异在于**敦煌、大柴旦落在节前还是国庆正日**，住宿成本差别显著。所有住宿价格通过 meituan-travel skill 真实查询（2026-08-26），机票价格同步通过 meituan-travel 实时获取。

## 方案一：正向环线（顺时针，推荐）

把大柴旦（9.28）、敦煌（9.29–9.30）安排在节前，国庆正日住嘉峪关（10.1）、张掖（10.2）、祁连（10.3）、西宁（10.4）——这四站国庆溢价均温和可控。

### 开销概览（人均）

| 分项 | 人均区间（元） | 说明 |
|---|---|---|
| 往返大交通（机票） | 约 1648–2104 | 详见 `行/机票方案对比.md`，最优组合 A2+C2（银川联程去+榆林经停回）¥1648/人 |
| 住宿（9 晚×4 间双人间） | 1005–1664 | 大柴旦/敦煌按节前价，仅嘉峪关/张掖/祁连/西宁落在国庆段 |
| 租车（2 辆×9–10 天，8 人分摊） | 750–1250 | 6000–10000 总额 |
| 油费+过路费（约 2800–3200 km） | 570–880 | 2 辆 SUV，约 4580–7040 总额 |
| 餐费（80–100/人/天×10 天） | 800–1000 | 已知口径 |

**预算区间：人均约 4900–6600 元**（全队 8 人约 3.9–5.2 万）

## 方案二：反向环线（逆时针）

经典走法，先走祁连、张掖、嘉峪关，敦煌（10.1–10.2）、大柴旦（10.3–10.4）落在国庆正日——这两站是全程住宿定价的头部，汉庭/全季国庆起价分别达 ¥820+ 和 ¥892+。

### 开销概览（人均）

| 分项 | 人均区间（元） | 说明 |
|---|---|---|
| 往返大交通（机票） | 约 1648–2104 | 与正向环线相同，机票价格与走法无关 |
| 住宿（9 晚×4 间双人间） | 1932–2518 | 敦煌 2 晚 + 大柴旦 2 晚落在国庆正日，占全程住宿的 60–70% |
| 租车（2 辆×9–10 天，8 人分摊） | 750–1250 | 同正向环线 |
| 油费+过路费（约 2800–3200 km） | 570–880 | 同正向环线 |
| 餐费（80–100/人/天×10 天） | 800–1000 | 已知口径 |

**预算区间：人均约 5800–7400 元**（全队 8 人约 4.6–5.9 万）

## 两方案对比

| 维度 | 正向环线（顺时针） | 反向环线（逆时针） |
|---|---|---|
| 人均预算 | **约 4900–6600 元** | 约 5800–7400 元 |
| 人均住宿 | 1005–1664 元 | 1932–2518 元 |
| 国庆正日过夜地 | 嘉峪关/张掖/祁连/西宁（溢价温和） | 敦煌×2/大柴旦×2（溢价凶猛） |
| 风光节奏 | 高原湖泊先行，海拔渐升再入戈壁 | 先入河西走廊，后半程上高原 |
| 驾驶强度 | 基本相同（2800–3200 km） | 基本相同（2800–3200 km） |

结论：**正向环线人均省约 ¥900–1000**（几乎全部来自住宿），仅国庆 4 晚人均省 ¥1000+；其余开销两方案完全一致。

## 核心发现

- **正向环线人均省约 ¥900–1000**（住宿），仅国庆 4 晚人均省 ¥1000+
- **兰州返程人均省 ¥447**（相比西宁直飞），全队 8 人省 ¥3500+
- 国庆段住宿定价头部：敦煌汉庭 10.1 起 ¥820+、大柴旦全季 10.2–10.3 起 ¥892+
- 黑独山 2025 年 5 月已开放为预约制景区（景交车 ¥60，禁止自驾进入）
- 大柴旦翡翠湖 2026 年起收费（¥50+¥40），原 2023 版"免费"已过时
- 鸣沙山已全面线上售票，现场无人工窗口
