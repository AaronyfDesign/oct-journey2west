## 4. 关键技术结论 / 踩过的坑

- **大段 string_replace/multi_edit 在正文混有弯引号（“” vs ""）时极易整批失败**（原子操作全回滚）。对策：先 `grep -n` 精确定位行号读原文，小步替换；整块重写时用 Python 脚本按行号切割（用完即删，如 `_fix_day5.py` 先例）
- **multi_edit 中任何一项 old_string 与 new_string 相同会导致整批拒绝**，注意剔除无操作项
- **docs/index.html 与 web/index.html 需手动 cp 同步**，且要验证（曾出现 cp 在同一命令中因 grep 先执行而未生效，靠 md5 校验发现）
- **本地起 HTTP 服务验证截图时端口可能被残留进程占用**，换端口（如 8766）并 kill 旧进程
- **web routePoints 坐标与图片裁切联动**：图一裁切/位移，坐标百分比必须重新标定，不能只改 CSS
- **git 提交规范**：中文提交信息描述变更内容；不主动 commit，除非任务流程要求（本项目历次均为任务完成后提交推送）
