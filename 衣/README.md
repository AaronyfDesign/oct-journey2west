# 衣 · 穿衣装备

> 对应总体行程规划中「一、衣」章节。

## 当前状态

目前无独立衣物专项文件，穿衣策略已在总体行程规划中概述。

## 已确定事项

- **穿衣策略**：洋葱式叠穿（短袖/长袖 T 恤 + 抓绒/薄羽绒 + 防风外套）
- **必备单品**：冲锋衣、薄羽绒服、墨镜、遮阳帽、防晒霜 SPF50+
- **鞋类**：运动鞋 + 拖鞋（鸣沙山必备）
- **特殊场景**：鸣沙山穿长裤、盐湖带鞋套或穿旧鞋
