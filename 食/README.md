## 各段饮食速查

| 路段 | 特征 | 推荐体验 |
|---|---|---|
| 西宁 | 青海美食集散地 | 炕锅羊肉、酸奶、甜醅、手抓羊肉 |
| 青海湖/黑马河 | 藏区风味，选择少价高 | 提前备速食；川菜/清真为主 |
| 大柴旦 | 小镇物资靠外运 | 提前在敦煌/西宁采购零食补给 |
| 敦煌 | 旅游成熟，选择丰富 | 沙洲夜市、驴肉黄面、杏皮水 |
| 嘉峪关/张掖 | 河西走廊融合风味 | 搓鱼子、炒炮仗、卷子鸡 |
| 祁连 | 草原牧区 | 牦牛肉、酥油茶、糌粑（可选） |
